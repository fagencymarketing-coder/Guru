# Структура проекта (навигатор) — куда что загружать

> ★ Главный принцип всего проекта: мы пишем о святых, ачарьях и Божествах, поэтому **при любом сомнении — уточняем или помечаем `[сверить]`, но не угадываем**. Осторожность важнее скорости. Сомнительное о святых и Божествах не публикуется. (Подробнее — в инструкции проекта.)

В Claude-проекте два разных места. Не перепутать:
- **ИНСТРУКЦИЯ ПРОЕКТА** — одно текстовое поле в настройках проекта. Туда идёт РОВНО ОДИН документ.
- **БАЗА ЗНАНИЙ** — сюда загружаются ФАЙЛЫ. Все остальные документы — сюда.

---

## → Загрузить дополнительно (собрать/получить)

8. **Транскрипты лекций/интервью** — по мере обработки (каждую новую лекцию гнать через п.4, класть как «6_...»).

## Как это работает вместе
1. Инструкция задаёт правила (в т.ч. «только из источника» и «расшифровки чистить по глоссарию»).
2. Новая лекция → чистим по **глоссарию** (п.4) → получаем «обработанную лекцию» (как п.6) → лучшие фрагменты после сверки с аудио уходят в **цитатник** (п.5).
3. Пост собирается из **цитатника** по **контент-плану** (п.3), с привязкой к **календарю** (п.2), с корректными именами по **списку гуру** (п.1), в тоне **брендбука** (п.7).

## Порядок первого запуска
1. Вставить инструкцию в поле проекта.
2. Загрузить файлы 1–6 в базу знаний.
3. Добавить брендбук.
4. Заполнить список гуру из официальных источников.
5. Обрабатывать 1–2 свежие лекции в неделю, пополняя цитатник.
