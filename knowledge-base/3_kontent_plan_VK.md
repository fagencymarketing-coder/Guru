# Контент-план для ВКонтакте — страницы Е.С. Бхакти Бхагаватамрита Кешава Свами Махараджа

> Черновик v1. Тональность и визуал свести с брендбуком atmabrand после его загрузки в проект. Любой контент от лица Гуру Махараджа — только после согласования с командой.

## Принципы
- Цель: вдохновлять, обучать, вовлекать в практику бхакти и в мероприятия. Не «продавать», а служить аудитории.
- Голос страницы — уважительный, тёплый, ясный. Пишем от лица канала/общины, а не «якобы от Махараджа».
- Точность важнее объёма: никаких выдуманных цитат; цитаты — только с источником.
- Регулярность важнее рывков.

## Ритм публикаций (базовый: 5 постов в неделю)
- **Пн — «Стих недели»**: стих из книг Шрилы Прабхупады + короткий понятный комментарий + источник.
- **Ср — «Практика бхакти»**: одна прикладная тема (джапа, садху-санга, прасад, чтение) — как применить в жизни.
- **Пт — «Наследие»**: Шрила Прабхупада / ачарьи / история линии парампары; либо анонс выходных программ.
- **Сб/Вс — «Живое общение»**: анонсы лекций/программ Гуру Махараджа, фрагменты лекций (с таймкодом/ссылкой), вопрос-ответ.
- **Плавающие**: праздники и Экадаши по вайшнавскому календарю (вставляются поверх сетки в нужные даты).

## Рубрикатор (можно чередовать)
1. Стих недели (Бхагавад-гита, Шримад-Бхагаватам, Ишопанишад…)
2. Практика бхакти (прикладное)
3. Слово о Шриле Прабхупаде / ачарьях
4. Календарь: праздник / Экадаши / день явления-ухода
5. Анонс: лекция, курс (Бхакти-шастри и др.), фестиваль
6. Фрагмент лекции Гуру Махараджа (нарезка + суть)
7. Вопрос-ответ / разбор частого сомнения новичка
8. Приглашение: «первые шаги», карта центров, «стать учеником»
9. Прасад / кухня бхакти (рецепт + смысл поднесения)
10. Отзыв / история преданного (с согласия)

## Шаблон поста для ВК
1. **Короткая подводка-контекст** (от редакции, только факт: кто сказал, на какой лекции/в каком тексте, когда, где).
2. **Дословная цитата** Гуру Махараджа / Махараджа / Шрилы Прабхупады — в кавычках, без пересказа своими словами. Допустимо: восстановление искажённых субтитрами слов/имён, удаление слов-паразитов, пропуски «…».
3. **Источник** (лекция/книга, дата, место, ссылка, таймкод).
4. **Хэштеги** — 3–6 релевантных.
5. **Визуал** — по брендбуку; идея указывается отдельно.
6. **Статус** — «черновик» до сверки цитаты с аудио/оригиналом.

> Своими словами — только контекст и организационное (время, ссылка). Не переформулировать, не «углублять», не додумывать мысль. Нет точной записи фразы — не публикуем.

# Пробные посты для ВК (по правилу «только из источника»)

Модель: пост строится вокруг проверенной цитаты (слова Махараджа / старшего вайшнава / писание) с указанием источника. Ниже — один готовый пост (источник есть) и два шаблона со «слотами» под цитату (источник берётся из базы знаний / vedabase, не выдумывается).

## Пост 1 — ГОТОВЫЙ. Рубрика «Слово Гуру Махараджа»
**Первая строка:** О чём Гуру Махарадж просит преданных в первую очередь?

Отвечая на вопрос о том, что он пожелал бы преданным, Гуру Махарадж сказал:

«Моё пожелание — стараться быть как можно добрее к преданным».

_Источник: Е.С. Бхакти Бхагаватамрита Кешава Свами, интервью для Железногорского общества сознания Кришны (рубрика «Садху-санга»), 19 июля 2018._

Полный фрагмент об этом — в интервью (ссылку/полную цитату брать из транскрипта в базе знаний).

#словоГуруМахараджа #садхусанга #вайшнавы #ББКС
_Идея визуала: портрет/фон по брендбуку, цитата крупной типографикой + подпись с источником._
_Статус: можно публиковать после сверки цитаты с оригиналом и оформления по брендбуку._

## Пост 2 — ШАБЛОН. Рубрика «Стих недели»
**Первая строка:** [цепляющий вопрос по теме стиха]

**Стих (писание, с атрибуцией):**
[перевод стиха] — [книга, глава, стих; издание ББТ / vedabase.io]
Пример проверенного якоря: Бхагавад-гита, 4.34 (этот стих вынесен и на bbks.online).

**Пояснение — ТОЛЬКО из источника (не сочинять):**
[короткий фрагмент из комментария Шрилы Прабхупады к этому стиху — взять с vedabase.io и привести с атрибуцией]
ИЛИ
[слова Гуру Махараджа об этом стихе из конкретной лекции — с указанием названия и даты]

**CTA (нейтральный):** вопрос к аудитории / ссылка на книгу.
#БхагавадГита #стихнедели #ББКС
_Статус: не публиковать, пока не вставлен реальный источник пояснения._

## Пост 3 — ШАБЛОН. Рубрика «Календарь» (пример: Гаура-пурнима)
**Операционная часть (можно писать):**
3 марта 2026 года — Гаура-пурнима, день явления Шри Чайтаньи Махапрабху (Гаурабда 540). Пост до восхода луны. Праздничная программа: [время, место, ссылка].

**Содержательная часть — ТОЛЬКО из источника:**
[о значении явления Шри Чайтаньи и санкиртаны — цитата из писания (напр. Чайтанья-чаритамрита) с указанием главы/стиха, ИЛИ слова Гуру Махараджа/старшего вайшнава из лекции с источником]

**CTA (нейтральный):** приглашение на программу.
#ГаураПурнима #ЧайтаньяМахапрабху #вайшнавскийкалендарь #ББКС
_Статус: дату и программу сверить по московскому календарю; содержательную часть заполнить проверенной цитатой; оформить по брендбуку._

---

**Общее примечание.** Пост 1 показывает целевой формат: реальная цитата + точный источник. Посты 2–3 намеренно оставлены шаблонами — там, где нужного источника пока нет в базе знаний, мы ставим «слот», а не досочиняем. Как только в проект загружены транскрипты лекций Махараджа и подключён vedabase, шаблоны заполняются реальными цитатами.
