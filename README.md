# bbks-smm

Контент и SMM для страниц Е.С. Бхакти Бхагаватамрита Кешава Свами Махараджа.

> ★ Главный принцип: мы пишем о святых, ачарьях и Божествах, поэтому **при любом сомнении — уточняем или помечаем `[сверить]`, но не угадываем**. Сомнительное о святых и Божествах не публикуется. Полные правила — в [`CLAUDE.md`](CLAUDE.md).

## Как это работает вместе

1. `CLAUDE.md` задаёт правила («только из источника», «расшифровки чистить по глоссарию»).
2. Новая лекция попадает в `raw/lectures/` → чистится по `4_glossariy…` → результат кладётся в `knowledge-base/` как «обработанная лекция» (по образцу файла 6) → после сверки с аудио лучшие фрагменты уходят в `5_citatnik.md`.
3. Пост собирается в `posts/` из цитатника, по контент-плану (`3_…`), с привязкой к календарю (`2_…`), с именами по списку гуру (`1_…`), в тоне брендбука.
